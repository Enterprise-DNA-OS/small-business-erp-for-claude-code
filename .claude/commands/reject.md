# reject

Reject a sales order waiting for approval, with the reason.

Run `npm run erp -- reject <order> <reason>`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
