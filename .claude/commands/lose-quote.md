# lose-quote

Mark a quote lost with the reason.

Run `npm run erp -- lose-quote <quote> <reason>`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Ask for the reason if the operator does not give one; it is what the quote history is for.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
