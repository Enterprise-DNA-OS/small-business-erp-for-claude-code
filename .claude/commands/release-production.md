# release-production

Release a planned run to the floor, so its components count as committed.

Run `npm run erp -- release-production <run>`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
