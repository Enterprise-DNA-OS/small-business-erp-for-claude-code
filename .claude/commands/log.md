# log

Record a factual follow-up note on an order, quote or production run.

Run `npm run erp -- log <order or run> <note>`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
