# count-due

List items with stock that have not been counted in 90 days, or ever.

Run `npm run erp -- count-due`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Suggest a short cycle count list for the week, most valuable first.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
