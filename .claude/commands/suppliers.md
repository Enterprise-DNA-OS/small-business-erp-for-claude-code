# suppliers

List suppliers with lead times and payment terms.

Run `npm run erp -- suppliers`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
