# export

Write a complete snapshot of every table to a JSON file.

Run `npm run erp -- export <file.json>`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
