# set

Change allowed fields on an existing record.

Run `npm run erp -- set <entity> <record> --field=value ...`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Show before and after.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
