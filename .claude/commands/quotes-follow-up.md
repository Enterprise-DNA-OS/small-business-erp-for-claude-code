# quotes-follow-up

List open quotes that have gone quiet for five days or expire within a week.

Run `npm run erp -- quotes-follow-up`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Offer /draft-quote to resend, or /win-quote and /lose-quote when the operator has the answer.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
