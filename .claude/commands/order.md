# order

Show one order or quote with its lines, the batches shipped and its follow-up notes.

Run `npm run erp -- order <order or quote>`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
