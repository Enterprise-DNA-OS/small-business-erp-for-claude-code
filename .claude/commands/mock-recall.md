# mock-recall

Run a practice recall on a batch: trace it, count customers and stock, and record the date.

Run `npm run erp -- mock-recall <batch> [--item=] [--on=]`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Time how long the trace takes and note any gap in the result.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
