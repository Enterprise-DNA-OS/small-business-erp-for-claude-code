# weekly-review

Write the Monday plan from three live reads: attention, ship plan and buy-and-make.

Run `npm run erp -- weekly-review`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Write it in this order: what is late and why, what can ship this week and what is short, what to buy or make today. One line each. Never invent dates or promises.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
