# item

Show one item: stock by warehouse, batches, what it is made from and what it goes into.

Run `npm run erp -- item <item>`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
