# receivables

List what customers owe from the ledger, aged current, 1-30, 31-60 and 60+.

Run `npm run erp -- receivables`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
