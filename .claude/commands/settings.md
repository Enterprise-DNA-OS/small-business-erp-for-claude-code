# settings

Show the business name, country, currency, GST number, record retention, margin floor, recall plan and last backup.

Run `npm run erp -- settings`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Point out anything blank that /compliance will flag.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
