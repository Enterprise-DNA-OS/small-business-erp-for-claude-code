# release-batch

Take a batch off hold.

Run `npm run erp -- release-batch <batch> [--item=]`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Ask who cleared it and log that with /log.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
