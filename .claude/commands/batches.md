# batches

List every batch with stock: warehouse, made and expiry dates, days left, hold state, supplier lot or production order.

Run `npm run erp -- batches`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
