# production-orders

List production orders: released first, then planned, with quantity left to make and the sales order each one is for.

Run `npm run erp -- production-orders`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
