# draft-chase

Draft a supplier follow-up for a late or due purchase order into drafts/.

Run `npm run erp -- draft-chase <purchase order>`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Nothing sends. Read /order first for notes from earlier calls.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
