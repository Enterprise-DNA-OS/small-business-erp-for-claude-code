# draft-order

Draft a sales order confirmation to the customer into drafts/.

Run `npm run erp -- draft-order <sales order>`. Add `--json` when you need to analyse the result further. Names match case-insensitively and IDs by prefix; if a name is ambiguous, list the candidates and ask.

Nothing sends.

Never send, pay or delete anything. Arguments in full: docs/cli.md.
